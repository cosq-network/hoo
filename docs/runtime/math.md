# Math & Utilities Reference

The `Math` class exposes mathematical primitives and constants backed by the standard C++ `<cmath>` library. Random number generation is provided via the `Random` class, utilizing a managed `std::mt19937_64` generator handle.

---

## 1. Constants

### `Math.getPi()`
- **Description:** Returns the mathematical constant π (pi), representing the ratio of a circle's circumference to its diameter. It is commonly used in trigonometry, geometry, and polar coordinate operations.
- **Syntax:** `Math.getPi() :double`
- **Parameters:** None
- **Return Value:** `double` — The approximate value of π (3.141592653589793).
- **Example:**
```hoo
func :int64 main() {
    var pi = Math.getPi();
    println("Pi: ".concat(pi.toString()));
    return 0;
}
```

### `Math.getE()`
- **Description:** Returns Euler's number `e`, which serves as the base for natural logarithms. This constant is foundational in calculus, compound growth models, and exponential scaling.
- **Syntax:** `Math.getE() :double`
- **Parameters:** None
- **Return Value:** `double` — The approximate value of e (2.718281828459045).
- **Example:**
```hoo
func :int64 main() {
    var e = Math.getE();
    println("e: ".concat(e.toString()));
    return 0;
}
```

### `Math.getTau()`
- **Description:** Returns the circle constant τ (tau), which is equivalent to 2π. It represents the full radian angle of a circle and simplifies many periodic and trigonometric formulas.
- **Syntax:** `Math.getTau() :double`
- **Parameters:** None
- **Return Value:** `double` — The approximate value of τ (6.283185307179586).
- **Example:**
```hoo
func :int64 main() {
    var tau = Math.getTau();
    println("Tau: ".concat(tau.toString()));
    return 0;
}
```

### `Math.getInf()`
- **Description:** Returns a double value representing positive floating-point infinity. It is typically produced by division of a positive number by zero or floating-point overflow.
- **Syntax:** `Math.getInf() :double`
- **Parameters:** None
- **Return Value:** `double` — Positive infinity.
- **Example:**
```hoo
func :int64 main() {
    var inf = Math.getInf();
    println("Infinity: ".concat(inf.toString()));
    return 0;
}
```

### `Math.getNegInf()`
- **Description:** Returns a double value representing negative floating-point infinity. It acts as an unbounded lower limit and is generated by division of a negative value by zero.
- **Syntax:** `Math.getNegInf() :double`
- **Parameters:** None

- **Example:**

### `Math.getNan()`
- **Description:** Returns the symbolic floating-point value for Not-a-Number (NaN). It signifies an undefined or unrepresentable numerical result, such as the square root of a negative value or zero divided by zero.

## 2. Basic Functions

### `Math.abs(x)`
- **Description:** Computes and returns the absolute non-negative magnitude of the given numeric value. If the input is negative, its negation is returned; otherwise, the value remains unchanged.
- **Syntax:**
  - `Math.abs(x: int64) :int64`
  - `Math.abs(x: int8) :int8`
  - `Math.abs(x: byte) :byte`
  - `Math.abs(x: double) :double`
  - `Math.abs(x: f8) :double`
- **Parameters:** `x` — The input numeric value.
- **Return Value:** The absolute value of `x`. Clamps `INT64_MIN` and `INT8_MIN` to avoid underflow/overflow.
- **Example:**
```hoo
func :int64 main() {
    var a = Math.abs(-42);
    var b = Math.abs(-3.14);
    println("Abs -42: ".concat(a.toString()));
    println("Abs -3.14: ".concat(b.toString()));
    return 0;
}
```

### `Math.sign(x)`
- **Description:** Evaluates the numeric sign of the given input value. It identifies whether the argument is positive, negative, or zero by returning a normalized step value.
- **Syntax:**
  - `Math.sign(x: int64) :int64`
  - `Math.sign(x: int8) :int8`
  - `Math.sign(x: byte) :byte`
  - `Math.sign(x: double) :double`
  - `Math.sign(x: f8) :double`
- **Parameters:** `x` — The input numeric value.
- **Return Value:** `-1` (or `-1.0`) if negative, `0` (or `0.0`) if zero, `1` (or `1.0`) if positive.
- **Example:**
```hoo
func :int64 main() {
    var s = Math.sign(-50);
    println("Sign of -50: ".concat(s.toString()));
    return 0;
}
```

### `Math.min(a, b)`
- **Description:** Compares two numerical inputs and extracts the smaller value. It supports several different type overloads to preserve high-level type safety during variable comparisons.
- **Syntax:**
  - `Math.min(a: int64, b: int64) :int64`
  - `Math.min(a: int8, b: int8) :int8`
  - `Math.min(a: byte, b: byte) :byte`
  - `Math.min(a: double, b: double) :double`
  - `Math.min(a: f8, b: f8) :double`
- **Parameters:** `a`, `b` — Numeric values to compare.
- **Return Value:** The smaller value of `a` and `b`.
- **Example:**
```hoo
func :int64 main() {
    var m = Math.min(10, 20);
    println("Min of 10 and 20: ".concat(m.toString()));
    return 0;
}
```

### `Math.max(a, b)`
- **Description:** Compares two numerical inputs and extracts the larger value. It determines the highest value between both operands while fully preserving the underlying primitive type mapping.
- **Syntax:**
  - `Math.max(a: int64, b: int64) :int64`
  - `Math.max(a: int8, b: int8) :int8`
  - `Math.max(a: byte, b: byte) :byte`
  - `Math.max(a: double, b: double) :double`
  - `Math.max(a: f8, b: f8) :double`
- **Parameters:** `a`, `b` — Numeric values to compare.
- **Return Value:** The larger value of `a` and `b`.
- **Example:**
```hoo
func :int64 main() {
    var m = Math.max(10, 20);
    println("Max of 10 and 20: ".concat(m.toString()));
    return 0;
}
```

### `Math.clamp(val, min, max)`
- **Description:** Restricts a double-precision floating-point value within an inclusive range bounded by `min` and `max`. If the value falls outside this range, it is snapped to the nearest threshold.
- **Syntax:** `Math.clamp(val: double, min: double, max: double) :double`
- **Parameters:**
  - `val` — The value to clamp.
  - `min` — The inclusive lower bound.
  - `max` — The inclusive upper bound.
- **Return Value:** `double` — Bound value.
- **Example:**
```hoo
func :int64 main() {
    var c = Math.clamp(15.5, 0.0, 10.0);
    println("Clamped: ".concat(c.toString()));
    return 0;
}
```

- **Syntax:** `Math.ceil(x: double) :double`
- **Parameters:** `x` — Input double.
- **Return Value:** `double` — Smallest integer greater than or equal to `x`.

- **Return Value:** `double` — Nearest integer, rounding halfway values away from zero.

```hoo
func :int64 main() {
```

## 8. Random Number Generation (`Random`)

### `new Random()`
- **Description:** Instantiates a new random number generator initialized with an automatic seed from the host operating system's device. It returns an Automatic Reference Counting (ARC) tracking pointer wrapper.
- **Syntax:** `new Random()`
- **Parameters:** None
- **Return Value:** An auto-seeded managed `Random` state instance reference handle.
- **Example:**
```hoo
func :int64 main() {
    var rng = new Random();
    rng.release();
    return 0;
}
```

### `new Random(seed)`
- **Description:** Instantiates a new random number generator initialized with a fixed user-defined seed. This produces a predictable and repeatable sequence of pseudo-random values.

### `state.release()`
- **Description:** Manually decrements the implementation tracking reference counter associated with a managed random handle object. Once reference counts settle to zero, the resource descriptor is cleanly recycled.
- **Syntax:** `rng.release() :void`
- **Parameters:** None
- **Return Value:** Nothing. Safely decrements reference counts and frees resources.
- **Example:**
