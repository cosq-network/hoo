# ISSUE-056: CSV Methods Referenced in Codegen But Missing From Runtime

## 1. Overview
The code generator's type inference system recognizes several CSV methods — `sort`, `filter`, `select`, `describe`, `avg`, `min`, `max`, `sum` — and assigns return types for them. These methods were initially thought to lack runtime implementations, but investigation confirms they are fully implemented and wired.

## 2. Technical Analysis
- **Codegen type inference**: `src/codegen/HVMCodeGenerator.cpp:3991-4003` — return types correctly mapped for all CSV instance methods.
- **Codegen dispatch**: Uses the prefix-based path (`classToPrefix("Csv")` → `"csv"`) which generates `_F_M_hoo_E_csv_*` mangled symbols matching JIT registration.

### Runtime implementations (all present in `src/runtime/lib/hoo_csv.h` and `hoo_csv.cpp`):
| Method | Function | Returns |
|--------|----------|---------|
| `sort(data, column, ascending)` | `hoo_csv_sort()` | `HooArray<HooMap>` |
| `filter(data, column, op, value)` | `hoo_csv_filter()` | `HooArray<HooMap>` |
| `select(data, columns)` | `hoo_csv_select()` | `HooArray<HooMap>` |
| `describe(data, column)` | `hoo_csv_describe()` | `HooMap` |
| `avg(data, column)` | `hoo_csv_avg()` | `HooString` |
| `min(data, column)` | `hoo_csv_min()` | `HooString` |
| `max(data, column)` | `hoo_csv_max()` | `HooString` |
| `sum(data, column)` | `hoo_csv_sum()` | `int64` |
| `count(data, column)` | `hoo_csv_count()` | `int64` |

### JIT registration (all present in `src/hvm/HVMJIT.cpp:4037-4053`):
Each method has a registered `_F_M_hoo_E_csv_*` symbol pointing to its JIT wrapper, which calls the corresponding C runtime function.

## 3. Verification
- All CSV methods are declared in `src/runtime/lib/hoo_csv.h` (lines 41-57)
- All CSV methods are implemented in `src/runtime/lib/hoo_csv.cpp` (lines 639-870)
- All CSV methods have JIT wrappers in `src/hvm/HVMJIT.cpp` (lines 2318-2440)
- All CSV methods are registered in the JIT symbol table (lines 4037-4053)
- Symbol names generated by codegen prefix-dispatch match the registered JIT symbols
